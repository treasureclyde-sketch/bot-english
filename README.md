# Личный ассистент в Telegram

Персональный бот, которому пишешь обычным текстом, а он сам разбирает сообщение
на **заметки**, **задачи/домашку** и **напоминания**, помнит контекст и напоминает
о делах. «Мозг» — Claude (модель **Sonnet**) через Anthropic API.

Однопользовательский и приватный: слушает только твой Telegram-аккаунт (`OWNER_ID`).

## Что умеет

Просто пиши как человеку:

| Ты пишешь | Что делает бот |
|-----------|----------------|
| «запиши, что пароль от вайфая 1234» | сохраняет заметку |
| «задали физику §12 к пятнице» | заводит задачу со сроком |
| «сделал физику» | находит задачу и отмечает выполненной |
| «что по домашке?» | показывает открытые задачи |
| «напоминай каждый вечер в 20:00 про английский» | ставит повторяющееся напоминание |
| «напомни завтра в 9 позвонить в банк» | ставит разовое напоминание |

Плюс сам присылает **утренний план** (что на сегодня и что просрочено) и
**вечерний итог** (что сделано, что ещё висит).

Команды (работают без обращения к модели, бесплатно):
`/tasks` `/notes` `/reminders` `/tz` `/pause N` `/resume` `/help`.

## Архитектура

Cloudflare Worker (бесплатно, всегда онлайн):

- `fetch()` — вебхук Telegram;
- `scheduled()` — крон раз в минуту (напоминания и обзоры);
- **D1** (SQLite) — заметки, задачи, напоминания, короткая память диалога;
- вызов **Claude Messages API** с набором инструментов (tool use).

```
src/
  index.js      — точка входа (вебхук + крон)
  handlers.js   — команды и приём свободного текста
  assistant.js  — системный промпт + цикл tool-use
  llm.js        — вызов Claude API
  tools.js      — инструменты (add_note/add_task/complete_task/add_reminder/…)
  engine.js     — крон: срабатывание напоминаний, утро/вечер
  db.js         — доступ к D1
  time.js       — часовые пояса и разбор дат (через Intl)
  telegram.js   — обёртка Telegram Bot API
  config.js     — модель, дефолты
schema.sql      — схема D1
```

Как это работает: твой текст → Claude с инструментами → Claude сам решает, что
вызвать (сохранить заметку, завести задачу, отметить сделанной, поставить
напоминание) → бот исполняет это в базе и отвечает по-человечески. В системный
промпт на каждый ход подкладываются текущее время, открытые задачи и активные
напоминания — поэтому на «что по домашке» он часто отвечает без лишних вызовов.

## Стоимость

Anthropic API оплачивается **по токенам, отдельно от подписки Claude Pro**
(Pro не нужен). Sonnet — примерно $2 за 1 млн входных и $10 за 1 млн выходных
токенов. Одно сообщение-разбор стоит доли цента; на активное личное
использование уходит порядка **единиц долларов в месяц**. Лимит трат ставится
в консоли Anthropic.

## Запуск

Нужны: аккаунт Cloudflare, токен бота от [@BotFather](https://t.me/BotFather),
твой `user_id` от [@userinfobot](https://t.me/userinfobot) и API-ключ с
[console.anthropic.com](https://console.anthropic.com) (закинь туда ~$5).
Пошагово — в [`DEPLOY.md`](DEPLOY.md). Коротко (через CLI):

```bash
npm install
npx wrangler d1 create assistant-db          # вставь id в wrangler.toml
npm run db:init                               # применить schema.sql
npx wrangler secret put BOT_TOKEN
npx wrangler secret put OWNER_ID
npx wrangler secret put WEBHOOK_SECRET        # любая случайная строка
npx wrangler secret put ANTHROPIC_API_KEY
npm run deploy
# открыть в браузере: https://<worker>.workers.dev/register?secret=<WEBHOOK_SECRET>
```

Потом напиши боту `/start`.
