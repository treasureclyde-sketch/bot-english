# Learning Bot — личный тренер-напоминалка в Telegram

> **Две версии в одном репозитории:**
> - **`worker/`** — для **Cloudflare Workers** (рекомендуется): бесплатно, всегда
>   онлайн, свой сервер не нужен. Инструкция по деплою — в [`worker/README.md`](worker/README.md).
> - **корень репозитория** — Python-версия для запуска на своём сервере/VPS
>   (`python bot.py` под systemd). Описана ниже.
>
> Функционал у обеих версий одинаковый. Ниже — про Python-версию.

---


Умный бот, который держит ритм по трём трекам обучения и не даёт перегореть.
Не просто «пора учить английский», а конкретное задание с прямой ссылкой,
оценкой времени и кнопками **Готово / Позже / Пропустить**. Помнит историю и
подстраивается: заметит, что трек проседает — предложит делать реже; заметит
два пропуска подряд — спросит «что случилось», а не будет долбить.

Четыре трека из коробки (настроены под Тимура, Уфа, UTC+5):

| Трек | Кадентность | Время | Длительность |
|------|-------------|-------|--------------|
| 🎧 6 Minute English | раз в 2 дня | 08:00 | 10 мин |
| 🦉 Duolingo Test | раз в 2 дня | 17:00 | ~20 мин |
| 📐 CSCA Math | раз в 3 дня | 19:00 | ~45 мин |
| 🧮 Пробник ЕГЭ | раз в неделю (сб) | 10:00 | ~2 ч |

**CSCA — это не «пойди порешай», а урок.** Уроки собраны из учебника CSCA Math
(тот же материал лежит интерактивным тренажёром в `study/csca-math-trainer.html`).
По каждой теме бот присылает: английскую экзаменационную лексику, подробную
русскую теорию с разбором ловушек, ключевые формулы, разбор примера, вопрос на
самопроверку и практику на [csca.app/ru/math/practice](https://csca.app/ru/math/practice).
9 тем идут по кругу (интервальное повторение): множества и неравенства, функции,
прогрессии, тригонометрия, прямые на плоскости, конические сечения, комплексные
числа, векторы и вероятность, производные. Математика — в юникоде (без Markdown),
длинный урок бьётся на несколько сообщений.

**Duolingo English Test** нужен для поступления в вузы Китая. Цель — **110–120**
(хватает большинству программ; топовые вузы иногда просят 120+). Бот гоняет по
типам заданий DET (Read and Complete, dictation, Read Aloud, interactive
reading/listening, writing/speaking sample и др.) с короткой подсказкой на
каждое, а периодически подкидывает полный бесплатный пробный тест.

**Тренажёр CSCA** (`study/csca-math-trainer.html`) — автономная веб-страница:
теория по 9 темам, словарь EN↔RU с поиском и тест на 10 вопросов с таймером.
Открывается в любом браузере, математика уже отрисована (KaTeX не нужен).
Команда `/csca` в боте даёт на неё ссылку.

Приоритет за один тик — один трек: 6min → Duolingo → CSCA → ЕГЭ.

## Архитектура (5 слоёв из ТЗ)

| Слой | Где в коде |
|------|-----------|
| 1. Хранилище (профиль, треки, история) | `db.py` — SQLite |
| 2. Логика напоминаний (приоритет, пропуски, перенос, воскресенье) | `scheduling.py`, `engine.py` |
| 3. Контент напоминания (задание + ссылка + время + 3 кнопки) | `reminders.py`, `content.py` |
| 4. Обратная связь и статистика (недельный/месячный отчёт, стрик, адаптация) | `stats.py`, `engine.py` |
| 5. Точки роста | см. раздел ниже |

Файлы:

- `bot.py` — точка входа, регистрация хендлеров, тик раз в минуту
- `handlers.py` — команды и нажатия кнопок
- `engine.py` — «тик»: что и когда отправить, отчёты, детекция пропусков
- `scheduling.py` — расчёт следующего срабатывания, правило воскресенья, перенос
- `reminders.py` — сборка текста напоминания и клавиатур
- `content.py` — библиотека контента (6min, двуязычные уроки CSCA, задания
  Duolingo, ЕГЭ, ресурсы)
- `stats.py` — отчёты и стрик
- `db.py` — слой хранилища
- `config.py` — дефолты профиля и треков

## Реализованные правила

- **Приоритет.** За один тик уходит максимум одно напоминание, в порядке
  6min → Duolingo → CSCA → ЕГЭ. Не приходит «оба разом».
- **Пропуски.** Два `Пропустить` подряд по треку → на следующий раз вместо
  напоминания вопрос «Что случилось?» с тремя кнопками (Тяжело / Нет времени /
  Надоел формат) и осмысленной реакцией на каждую.
- **Перенос.** Любое напоминание можно отложить на **+2 часа** или **на завтра**
  (не «сделать или нет», а «когда»).
- **Воскресенье.** В воскресенье напоминаний нет вообще — только вечерний
  недельный отчёт.
- **Стрик.** Сколько дней подряд было хотя бы одно `Готово`.
- **Недельный отчёт** (вс, вечер): сделано X из N по каждому треку + стрик.
- **Месячный отчёт** (1-е число, утро): общий %, какой трек проседает, и
  кнопка-предложение снизить частоту проседающего трека (адаптивно, не жёстко).
- **Пауза.** `/pause N` — тишина на N дней, потом бот включается сам.

## Команды

```
/start        запуск и приветствие
/status       план на сегодня + стрик
/tracks       треки: вкл/выкл и сдвиг времени кнопками
/pause N      пауза на N дней (по умолчанию 1)
/resume       снять паузу
/tz Zone      часовой пояс (напр. /tz Asia/Yekaterinburg)
/report       недельный отчёт сейчас
/csca         ресурсы по математике
/duo          про Duolingo Test и ресурсы
/help         помощь
```

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather), скопируй токен.
2. Узнай свой `user_id` у [@userinfobot](https://t.me/userinfobot).
3. Настрой окружение:

   ```bash
   pip install -r requirements.txt
   cp .env.example .env
   # впиши BOT_TOKEN и OWNER_ID в .env
   ```

4. Запусти:

   ```bash
   python bot.py
   ```

5. Напиши боту `/start`.

Бот однопользовательский: команды принимает только `OWNER_ID`. База — файл
SQLite (`data/bot.sqlite3`), переживает перезапуск. Держи процесс живым
(`systemd`, `tmux`, докер, VPS) — тик каждую минуту решает, что пора отправить.

## Тесты

```bash
python tests/test_logic.py
```

Проверяют хранилище, расписание (в т.ч. пропуск воскресенья), стрик, детекцию
пропусков, прогрессию контента и адаптивное предложение месячного отчёта.

## Слой 5 — точки роста (задел на потом)

Основа готова; дальше можно расширять, не ломая слоёв:

- Интеграция с `csca.app` по API — бот видит реальные результаты пробников и
  добивает именно слабые темы (сейчас уроки идут по кругу по фиксированному
  порядку).
- Приём ответа на вопрос «Проверь себя» кнопками прямо в чате (сейчас ответ
  просто дан в конце урока; в тренажёре — интерактивно).
- Больше тем/задач в `study/` тренажёр и, соответственно, в уроки бота.
- Синхронизация балла Duolingo с целевыми порогами вузов (напомнить, когда
  дотянул до нужного).
- Разблокировка тем по неделям вместо «по порядку блоков».
